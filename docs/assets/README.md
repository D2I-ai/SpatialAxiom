# Homepage assets

Put logo/wordmark and showcase media here, then reference them from `../index.html`:

- `logo.svg` / `logo.png` - hero/nav logo (optional)
- showcase examples (e.g. `showcase-1.jpg`, `showcase-1.mp4`, ...) - replace the
  three placeholder `<figure>` blocks in the Showcase section of `index.html`.

All paths in `index.html` are relative, so keep media inside this folder.
